## POST 4 — Security quick-win: the ClickFix "run this command" scam  (SIMPLE)

### X (@builtbyswami) — card_4
🔒 A scam is hitting 100,000+ sites this week.

A fake "verify you're human" page tells you to paste a command into Windows Run / Terminal. 🪤

That command installs malware instantly.

Rule: no real site asks you to run a command. Close the tab. ✅

#CyberSecurity

### Threads (@longpressnews) — card_4
🔒 A scam is spreading across 100,000+ websites this week.

You hit a page that says "verify you're human" — then it tells you to copy a code and paste it into Windows Run or Terminal. 🪤

Do it, and you just installed malware yourself. It's called ClickFix, and it's everywhere right now.

The rule that keeps you safe: no real website EVER needs you to run a command. Close the tab. ✅
